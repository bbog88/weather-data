# 진주·부산 날씨 수집기

Open-Meteo의 현재 날씨 데이터를 진주와 부산에 대해 수집하고, 지역별 CSV 파일에 한 행씩 누적하는 프로그램입니다.

## 수집 위치

| 지역 | 위도 | 경도 | 저장 파일 |
| --- | ---: | ---: | --- |
| 진주 | 35.1800 | 128.1076 | `data/jinju_weather.csv` |
| 부산 | 35.1796 | 129.0756 | `data/busan_weather.csv` |

## CSV 항목

- 수집 시각과 데이터 기준 시각
- 지역명, 위도, 경도
- 기온과 체감온도
- 상대습도
- 강수량
- WMO 날씨 코드

구름량, 풍속, 풍향은 수집하지 않습니다.

## 직접 실행

Python 3.9 이상이 필요하며 별도의 패키지 설치는 필요하지 않습니다.

```shell
python collect_weather.py
```

처음 실행하면 `data` 폴더와 지역별 CSV 파일을 자동으로 생성합니다. 같은 데이터 기준 시각의 행이 이미 있으면 중복 저장하지 않습니다. API 호출이나 필수 데이터 확인에 실패하면 종료 코드 1로 종료합니다.

## 자동 실행

`.github/workflows/collect-weather.yml`이 매시간 17분에 실행됩니다. GitHub의 예약 실행은 UTC 기준이지만 매시간 실행이므로 한국시간에도 매시간 한 번 실행됩니다. GitHub 서비스 상황에 따라 실제 시작 시각은 다소 늦어질 수 있습니다.

워크플로는 다음 순서로 동작합니다.

1. 저장소를 내려받고 Python 3.13을 준비합니다.
2. 진주와 부산의 최신 날씨를 수집합니다.
3. 두 CSV를 스테이징합니다.
4. 데이터 중복으로 파일 변화가 없더라도 시간별 실행 기록을 위한 빈 커밋을 허용합니다.
5. API 호출이 성공한 경우에만 커밋을 기본 브랜치에 푸시합니다.

GitHub 저장소 연결과 최초 업로드는 이후 단계에서 진행합니다.
